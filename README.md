# Reading the Machine

A public documentation project on process analytics for pharmaceutical and biotech manufacturing.

**Live site : https://arnaudcoqueblin.github.io/reading-the-machine/**

## What this is

A series of chapters and tools documenting how to read, interpret, and act on operational data from manufacturing equipment -- alarm logs, batch records, historian data -- using statistical methods grounded in GxP requirements.

## Content

- **Chapters** : applied case studies (freeze-dryer pump degradation, FMEA augmented with historian data)
- **Toolbox** : machinelogR (R package for discrete event log analysis), FDSim (freeze-dryer simulator)
- **Ecosystem** : how the tools connect to the manufacturing data stack (PI System, MES, ELN)
